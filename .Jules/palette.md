## 2025-04-06 - Missing ARIA Labels on Modals/Interactive Elements
**Learning:** Icon-only buttons used for critical interface interactions (like Edit, Close Modal, or Add items) frequently lack both `aria-label`s and standard tooltips (`title`). This pattern was observed in `ServiceContainer.vue`.
**Action:** Always verify that icon-only interactive elements contain both `aria-label` (for screen readers) and `title` (for mouse hover guidance) to ensure full accessibility.
