## 2024-04-09 - Accessible Focus States on Interactive Icons
**Learning:** Icon-only elements (like bare SVG paths or text characters like `+` / `-`) must be wrapped in semantic `<button>` tags with `type="button"` to ensure native keyboard navigability and avoid accidental form submissions. Relying on `@click` directly on `<svg>` or `<div>` elements hides the interactivity from screen readers and prevents keyboard focus.
**Action:** Always wrap interactive SVGs in `<button>` tags with `aria-label`, `title`, and explicit `focus-visible:` utility classes to guarantee screen reader context and visual keyboard focus indicators.
