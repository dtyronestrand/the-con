## 2024-05-14 - Keyboard Accessibility in Interactive Elements
**Learning:** Relying solely on `group-hover:opacity-100` to show interactive elements hides them from keyboard users who cannot hover. Additionally, icon-only buttons need `aria-label` and `title` attributes to be perceivable by screen reader users and to display tooltips.
**Action:** When adding hover states that reveal actionable elements, ensure there is a corresponding `focus-within:opacity-100` state. Always use accessible names (`aria-label`, `title`) and clear `focus-visible` styling on icon-only buttons.
## 2024-05-15 - Icon-only buttons and default focus outlines
**Learning:** Adding Tailwind focus rings (like `focus-visible:ring-2`) to icon-only interactive elements without also removing the browser's default focus ring (`focus-visible:outline-none`) creates an overlapping, visually cluttered double-focus state. Additionally, `aria-hidden="true"` should be added to the SVG icon itself when the wrapper button handles the accessible labeling.
**Action:** Always combine `focus-visible:outline-none` with custom focus rings. Remember to explicitly hide purely decorative internal icons from screen readers when their container has an `aria-label`.
